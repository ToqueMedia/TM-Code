## Estrutura
- **Backend** (`backend/src/server.ts` + `backend/src/routes/auth.ts`): Express com endpoints do auth-proxy:
  - `POST /api/auth/proxy/signup` — registo email/password
  - `POST /api/auth/proxy/signin` — login email/password
  - `POST /api/auth/proxy/google` — login Google via Identity Toolkit
  - `POST /api/auth/proxy/refresh` — refresh token
  - `POST /api/auth/sync` — upsert do user na DB (JWT verificado via JWKS)
  - `GET /api/auth/me` — dados do user autenticado
- **DB**: SQLite + Prisma com tabela `users` (`uid`, `email`, `name`, `avatarUrl`, `role`, etc.)
- **Frontend**: React + Vite + Tailwind + React Router

## Páginas
