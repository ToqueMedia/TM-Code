## What if programming was a conversation?

Most IDEs were built to write code. TM Code was built to **think code**.

You describe what you need — in natural language, like you would with a colleague. The AI agent writes the code, shows you changes line by line, runs the project, and opens a live preview. Everything happens in the same window, without switching tabs.

When you want to edit code with your own hands, the full editor is one click away. But you'll probably prefer to keep the conversation going.

## How it changes the way you work

**You say it. The agent builds it.**

- **Start with chat** — No need to open files or remember syntax. Say what you want and watch it happen.
- **Live preview** — See your app running in real time as the agent writes each line.
- **Visible changes** — Every code change appears as a diff you can accept or reject before applying.
- **Powered by MiMo** — Xiaomi's MiMo V2.5 models with native 1M-token context windows and strong agentic capabilities.
- **Built-in terminal** — The agent runs commands for you, but you always have access to the terminal when you need it.
- **External tools (MCP)** — Connect databases, APIs, and services directly to the agent's workflow.
- **Ready-to-use projects** — Start with templates for React, Next.js, Vue, Svelte, Angular, Express, NestJS and more.
- **Per-project isolation** — Each project can run in its own isolated environment, conflict-free.

## Who is TM Code for?

- **Developers who want to ship faster** — Less time configuring, more time creating.
- **Those who are learning** — Describe what you want and learn from the code the agent generates.
- **Small teams doing big team work** — An agent that multiplies your capacity.
- **Creators who think in product, not syntax** — Focus on the "what" and let the agent handle the "how".
